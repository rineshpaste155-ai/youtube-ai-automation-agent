
# YouTube AI Content Execution Commands

Use these commands with ChatGPT.

## 1. CONTENT_IDEAS
Generate original video ideas for the specified channel and audience.

## 2. SHORTS_SCRIPT
Create a complete YouTube Shorts script with hook, narration, scenes, visuals and CTA.

## 3. LONG_FORM_SCRIPT
Create a complete long-form video script with chapters, narration and visual directions.

## 4. FULL_VIDEO_PACKAGE
Create a complete production-ready video package using the content package template.

## 5. SEO_PACKAGE
Generate titles, description, keywords, hashtags and thumbnail concepts.

## 6. THUMBNAIL_CONCEPT
Create detailed thumbnail concepts and AI image-generation prompts.

## 7. CONTENT_CALENDAR
Build a channel-specific content calendar based on the requested publishing frequency.

## 8. ANALYTICS_REVIEW
Analyse user-provided YouTube analytics and recommend improvements.

## Execution Rules

1. Read master-agent-instructions.md.
2. Read the relevant agent instructions.
3. Read the channel profile when relevant.
4. Follow the content production workflow.
5. Use the content package template when creating a full package.
6. Never invent analytics or performance data.
7. Prefer free browser-based tools.
8. Mark all completed content as Pending Review.
9. Require human approval before publishing.
10. Never automatically publish or schedule videos.
