YOUTUBE AI CONTENT CREATION — MASTER COMMAND GUIDE

Repository: youtube-ai-automation-agent
Purpose: General-purpose YouTube content creation and production
Execution Engine: ChatGPT
Instruction & Storage Hub: GitHub
Video Generation: Google Flow
Publishing: Manual, with human approval

---

1. HOW TO START A NEW SESSION

At the beginning of a new ChatGPT conversation, use:

"LOAD_YOUTUBE_WORKSPACE"

Instructions:

1. Read the GitHub repository:
   https://github.com/rineshpaste155-ai/youtube-ai-automation-agent

2. Read these files:
   
   - master-agent-instructions.md
   - research-agent.md
   - content-growth-agent.md
   - config/channel-profile.yml
   - tasks/content-production/README.md
   - tasks/content-production/content-agent-workflow.md
   - tasks/content-production/content-package-template.md
   - tasks/content-production/commands.md
   - tasks/content-production/content-execution-request.md

3. Use these files as operating instructions for the current conversation.

4. Ask for missing essential project information only.

5. Do not assume that all channels use the same niche, language, audience or video format.

6. Never claim that the repository is automatically synchronized with ChatGPT.

2. CHANNEL SETUP COMMANDS

CHANNEL_SETUP

Create a complete channel profile.

Deliverables:

- Channel positioning
- Niche and sub-niche
- Target audience
- Country and language
- Channel tone and personality
- Content pillars
- Visual identity
- Upload frequency
- Growth objectives

CHANNEL_AUDIT

Analyse an existing YouTube channel.

Deliverables:

- Branding
- Channel positioning
- Content quality
- Titles and thumbnails
- SEO
- Audience retention opportunities
- Competitor comparison
- Improvement plan

Use actual channel data where available. Never invent analytics.

CHANNEL_BRANDING

Create:

- Channel name suggestions
- Logo concepts
- Banner concepts
- Channel description
- Profile identity
- Brand colours
- Visual guidelines

CHANNEL_KEYWORDS

Generate:

- Primary keywords
- Secondary keywords
- Niche keywords
- Search-intent groups
- Competitor keyword opportunities

Clearly distinguish researched keywords from suggestions.

6. GOOGLE FLOW VIDEO GENERATION COMMANDS

FLOW_MASTER_REFERENCE

Create a permanent character or visual reference specification.

Include:

- Character identity
- Facial features
- Body proportions
- Clothing
- Accessories
- Colours
- Art style
- Lighting
- Background
- Camera style

For recurring characters, establish a master reference image before generating clips.

FLOW_SCENE_BREAKDOWN

Convert a script into individual Google Flow scenes.

For every scene provide:

- Scene number
- Duration
- Narration
- Visual action
- Camera movement
- Environment
- Lighting
- Transition
- Character reference requirements

FLOW_VIDEO_PROMPTS

Generate copy-ready Google Flow prompts.

Every prompt must specify:

- Duration
- Aspect ratio
- Character reference
- Character consistency
- Scene action
- Camera movement
- Visual style
- Lighting
- Environment
- Negative instructions

FLOW_CHARACTER_CONSISTENCY

Check recurring character consistency.

Maintain:

- Same reference image
- Same facial structure
- Same clothing
- Same accessories
- Same colours
- Same proportions
- Same visual style

Do not independently redesign recurring characters between clips.

FLOW_CLIP_QC

Review generated clips for:

- Character consistency
- Visual quality
- Distorted anatomy
- Camera movement
- Audio quality
- Scene continuity
- Duration
- Aspect ratio

FLOW_REGENERATION

Create corrected prompts for clips that fail quality checks.

Preserve all previously approved character specifications.

12. FINAL QUALITY AND APPROVAL COMMANDS

FINAL_QC

Run a complete quality check before publishing.

Review:

- Originality
- Accuracy
- Copyright risks
- Visual consistency
- Audio
- Captions
- SEO
- Audience suitability
- Platform suitability

APPROVAL_REVIEW

Prepare a final human approval checklist.

Every content package must have one status:

- Draft
- Pending Review
- Approved
- Rejected

Only human approval can authorise publishing.

PUBLISHING_PACKAGE

Prepare final:

- Video title
- Description
- Thumbnail
- Tags and hashtags
- Pinned comment
- Publishing recommendations

Never automatically publish or schedule content.

TOPIC: A life lesson from Lord Ganesha

LANGUAGE: Hindi

FORMAT: YouTube Shorts

DURATION: 45 seconds

VIDEO GENERATOR: Google Flow

CLIP DURATION: 15 seconds

VOICEOVER: Generated inside Google Flow

VISUAL STYLE: Traditional devotional painting animation

CHARACTER CONSISTENCY: Use the approved master reference image

OUTPUT: Complete production-ready package

Execute the command using the repository instructions.

14. RECOMMENDED PRODUCTION WORKFLOW

Follow this sequence for every new video:

1. LOAD_YOUTUBE_WORKSPACE
2. RESEARCH_TOPIC
3. CONTENT_IDEAS
4. Select and approve a topic

6. SCRIPT_QC
7. FLOW_MASTER_REFERENCE

9. FLOW_VIDEO_PROMPTS
10. Generate clips in Google Flow
11. FLOW_CLIP_QC

13. VIDEO_ASSEMBLY
14. SUBTITLE_GENERATOR
15. SEO_PACKAGE
16. THUMBNAIL_CONCEPT
17. FINAL_QC
18. APPROVAL_REVIEW
19. PUBLISHING_PACKAGE

A user may skip steps that are not required.

15. OPERATING RULES

1. Support all YouTube niches, countries and languages.
2. Follow the channel-specific profile when supplied.
3. Prefer free and browser-based tools.
4. Do not require local software installation.
5. Do not require paid APIs or paid AI credits.
6. Explain limitations of free tools.
7. Never invent analytics or research findings.
8. Maintain recurring character consistency.
9. Respect copyright and platform policies.
10. Never automatically publish or schedule content.
11. Obtain human approval before publishing.
12. Keep every content package actionable and production-ready.
