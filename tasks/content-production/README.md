
# YouTube Content Production System

## Purpose

This folder contains the reusable content production framework for any YouTube channel or niche.

## Production Stages

1. Content planning and ideation
2. Hook and script development
3. Scene-by-scene production planning
4. AI image and video prompts
5. Voiceover and captions
6. YouTube SEO package
7. Quality assurance
8. Human approval

## Supported Formats

- YouTube Shorts
- Long-form videos
- Educational videos
- Storytelling videos
- Animated videos
- Tutorials
- Reviews
- Entertainment
- Other channel formats

## Operating Rules

- Follow the master-agent-instructions.md file.
- Follow content-growth-agent.md.
- Use the channel profile when relevant.
- Adapt every output to the requested channel.
- Prioritize originality and audience retention.
- Never invent facts or analytics.
- Keep production browser-based and free wherever possible.
- Require human approval before publishing.

## Output Status

Every content package must have one of these statuses:

- Draft
- Pending Review
- Approved
- Rejected

No automatic publishing is permitted.
